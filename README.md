\# Padel Score \& Tracker for Fitbit Versa 3



A dedicated Padel score counter and activity tracker built for the \*\*Fitbit OS SDK 5.0\*\*. This app allows players to keep track of their games directly from their wrist while recording their physical activity as a tennis session.



\## 🚀 Features



\* \*\*Padel Scoring:\*\* Easily track points (0, 15, 30, 40, Ad) and games for both teams.

\* \*\*Exercise Integration:\*\* Automatically starts a "Tennis" exercise session to track calories and heart rate.

\* \*\*Smart Stats Toggle:\*\* Click the heart rate label to toggle between current BPM and the local clock.

\* \*\*Pause Menu:\*\* Press the physical back button to access a custom pause menu showing:

&nbsp;   \* Active session duration.

&nbsp;   \* Calories burned.

&nbsp;   \* Option to Resume or Finish the match.

\* \*\*i18n Support:\*\* Fully localized in English and Portuguese.

\* \*\*Undo Function:\*\* Long-press the reset button to end the session, or short-press to undo the last point.
